ThiranX – Employee Task Management System
Overview

ThiranX is a console-based Employee Task Management System developed using Core Java to streamline task assignment, employee management, and work tracking within an organization. The application enables managers to assign tasks, monitor employee activities, and track task completion efficiently.

The project focuses on clean object-oriented design, modular architecture, and effective task workflow management.
